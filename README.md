# README: Модель предсказания знаков изменения свободной энергии связывания (ddG)

## Описание

Это решение задачи предсказания знака изменения свободной энергии связывания (ddG) с использованием данных из базы SKEMPI 2.0. Задача заключается в классификации значений ddG как положительных или отрицательных. Для этого я использовала модель машинного обучения CatBoost, которая особенно хороша при работе с категориальными признаками.

## Структура проекта

Проект состоит из одного Python-скрипта, который выполняет все необходимые шаги: загрузку данных, их обработку, обучение модели и оценку её качества. Каждый шаг подробно прокомментирован в коде.

## Необходимые библиотеки

Для запуска проекта нужно установить несколько библиотек, которые использовались в коде. Чтобы установить все нужные пакеты, просто выполните следующую команду:

## Шаги выполнения

### 1. Загрузка и обработка данных

* Загружаю данные из файла `skempi_v2.csv`.
* Пропуски в данных визуализируются с помощью библиотеки `missingno`. Если в столбце пропуски составляют более 10%, я его удаляю, так как это может значительно повлиять на точность модели.
* Преобразую строковые столбцы, содержащие числовые данные (например, `Affinity_mut (M)` и `Affinity_wt (M)`), в формат float, чтобы с ними можно было работать.

### 2. Расчёт изменения свободной энергии связывания (ddG)

* С помощью стандартной формулы для расчёта изменения свободной энергии связывания (ddG) вычисляю значение для каждого примера в данных:

  $$
  ddG = RT \times (\ln(\text{Affinity\_mut}) - \ln(\text{Affinity\_wt}))
  $$

  где R — это газовая постоянная, а T — температура.

### 3. Классификация значений ddG

* ddG преобразуется в бинарную переменную: если значение ddG положительное, присваиваю метку `1`, если отрицательное — метку `-1`.

### 4. Разделение данных

* Данные разделяю на признаки (X) и целевую переменную (y), затем делю их на обучающую и тестовую выборки с помощью функции `train_test_split`.

### 5. Обучение модели

* Для обучения использую модель CatBoost, которая хорошо работает с категориальными признаками. Модель обучается на 1000 итерациях с заданной глубиной деревьев и темпом обучения.

### 6. Оценка модели

* После обучения модели оцениваю её качество по меткам точности (accuracy), F1-мере, precision и recall. Результаты показывают, насколько хорошо модель классифицирует данные.

### 7. Результаты

* Точность модели (accuracy) составила **84%**.
* F1-Score — **0.90**.
* Precision — **87%**.
* Recall — **95%**.

Это значит, что модель работает довольно стабильно и может использоваться как базовое решение для задачи.
